# 🎉 Remembirth

**Never forget a birthday again.** Remembirth is a simple Android app that keeps track of the
birthdays of the people you care about and reminds you when one is coming up.

## Building

1. Clone the repository and open it in a recent version of **Android Studio**.
2. Let Gradle sync.
3. Run the `app` configuration on an emulator or a device with Android 7.0 or newer.

Run the unit tests with:

```bash
./gradlew test
```
