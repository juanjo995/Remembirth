# Remembirth

Simple birthday reminder.

<img width="365" height="239" alt="sample" src="https://github.com/user-attachments/assets/767ae1e3-80c7-4a1b-b3fa-b94c086b6ce1" />

Add as many people as you want to the file dates.txt, and run the executable on the same path where this file is located.

On Windows:

`.\Remembirth.exe`

(Or double click on the executable)

On macOS and Linux:

`./Remembirth`
